# Week 7 纠错记录

> 审查日期：2026-08-28｜状态：`DERIVATIONS_PRESENT / VALIDITY_PARTIAL`

## C1：推导文档完成不等于脱稿能力验收完成

- 原问题：五份 Markdown 存在，随后被总结为“五个推导全部完成”；原计划还要求复习、白板、照片或录音。
- 为什么错：文档性产物与行为能力是两种证据。
- 已修复：分开标记“推导材料存在”和“脱稿复述未验证”。

## C2：用 `W_0` 的谱解释 `ΔW` 低秩

- 原问题：文档从 `W_0` 奇异值衰减直接推导低秩修正足够，并给出不存在的 Qwen ΔW 数字。
- 为什么错：`W_0` 的可压缩性与任务更新 `ΔW` 的有效秩不是同一个命题；“小修正”也不必然意味着低秩。
- 已修复：SVD 章节改为一般数学工具；LoRA 低秩是需要真实更新和下游消融支持的经验假设。

## C3：alpha/rank 与 learning rate 的关系写得过强

- 原问题：写成固定 alpha 后调 rank 无需重新调 learning rate。
- 为什么错：rank、初始化、scaling、优化器和学习率会共同改变更新动态。
- 已修复：改为常见参数化直觉，不再承诺无需重调。
